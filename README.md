# Plateforme visa — démonstration (Solares Bauen)

Suivi des visas de documents d'exécution. Deux applications Streamlit, données fictives :

- **Plateforme visa interne** (`app.py`) : https://plateforme-visa-interne.streamlit.app/
- **Plateforme visa partenaires** (`portail.py`) : https://plateforme-visa-partenaires.streamlit.app/

Dans cette démonstration, chaque application a sa propre base (SQLite) : un dépôt fait sur l'une
n'arrive pas sur l'autre, et les saisies sont effacées à chaque redémarrage.
